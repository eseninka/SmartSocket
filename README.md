# SmartSocket – интеллектуальная система мониторинга и учёта электроэнергии

SmartSocket – это открытая платформа для умной розетки, которая позволяет в реальном времени измерять параметры электропотребления подключённых приборов, накапливать статистику и визуализировать данные через локальный OLED-дисплей, Telegram-бота и Home Assistant. Проект направлен на выявление фантомного потребления и повышение энергоэффективности.

## Описание проекта

Многие современные электроприборы потребляют энергию даже в выключенном состоянии – так называемое **фантомное потребление** (standby). В масштабах одной квартиры потери могут составлять до 10% от общего расхода, а в масштабах страны – гигаватт-часы и миллиарды рублей. Существующие «умные» розетки либо закрыты, либо не дают детальной аналитики.

SmartSocket решает эту проблему: устройство измеряет ток, напряжение, мощность, коэффициент мощности и накопленную энергию, передаёт данные на сервер по MQTT и позволяет пользователю отслеживать статистику через удобные интерфейсы.

## Архитектура системы

Система состоит из трёх основных компонентов:

1. **Умная розетка** на базе ESP32 с датчиками тока ACS712 и напряжения ZMPT101B, OLED-дисплеем и автоматическим выключателем.
2. **Серверная часть** на Python, которая принимает данные по MQTT, сохраняет их в PostgreSQL и предоставляет интерфейсы (Telegram-бот, Home Assistant).
3. **База данных PostgreSQL** для хранения мгновенных значений и расчётных параметров.

## Программная часть

### Прошивка ESP32
Написана в среде Arduino IDE, использует библиотеки:
- `WiFi`, `PubSubClient` – для связи с MQTT-брокером.
- `Adafruit_SSD1306`, `Adafruit_GFX` – для работы с OLED-дисплеем.
- `ArduinoJson` – для формирования JSON-пакетов.
- `ACS712`, `ZMPT101B` – для работы с датчиками.

Основные функции:
- Синхронный сбор 20 мгновенных значений тока и напряжения за период 20 мс.
- Расчёт RMS тока и напряжения, активной и полной мощности, cos φ.
- Вывод на дисплей текущих параметров.
- Отправка данных в MQTT-топик `kvant/R22/BV/update`.

Исходный код: `send_to_wqtt.ino`, `read_AC.h`.

### Серверный Python-скрипт
Использует библиотеки:
- `paho-mqtt` – подписка на MQTT-топик.
- `psycopg2` – взаимодействие с PostgreSQL.
- `json` – парсинг входящих данных.
- `numpy`, `pandas`, `matplotlib` – для анализа и построения графиков.

Функции:
- Приём данных, сохранение в таблицы `data_current`, `data_voltage`, `calculation`.
- Расчёт накопленной энергии и стоимости.
- Публикация обработанных данных в топик `kvant/R22/BV/reception`.
- Генерация графиков по запросу (через Jupyter notebook `visual_SmartSocket.ipynb`).

### База данных
Структура таблиц описана в файле `main_tables.sql`:
- `data_current` – хранит массивы мгновенных значений тока и RMS.
- `data_voltage` – массивы мгновенных значений напряжения и RMS.
- `calculation` – рассчитанные параметры (P, I, V, cosφ).

## Установка и запуск

### Требования
- ESP32 с поддержкой Arduino.
- Python 3.7+ с установленными библиотеками из `requirements.txt`.
- PostgreSQL (локально или удалённо).
- MQTT-брокер (например, публичный broker.hivemq.com или арендованный на wqtt.ru).

### Шаги

1. **Клонируйте репозиторий**:
   ```bash
   git clone https://github.com/eseninka/SmartSocket.git
   cd SmartSocket
   ```

2. **Прошивка ESP32**:
   - Откройте `send_to_wqtt.ino` в Arduino IDE.
   - Установите необходимые библиотеки (см. список выше).
   - Настройте параметры Wi-Fi и MQTT в файле.
   - Загрузите скетч на ESP32.

3. **Серверная часть**:
   - Установите зависимости:
     ```bash
     pip install -r requirements.txt
     ```
   - Настройте подключение к PostgreSQL в `main.py` (параметры `host`, `user`, `password`, `database`).
   - Создайте таблицы, выполнив скрипт `main_tables.sql`.
   - Запустите сервер:
     ```bash
     python main.py
     ```

4. **Визуализация**:
   - Для построения графиков используйте Jupyter notebook `visual_SmartSocket.ipynb`.
   - Для интеграции с Home Assistant настройте MQTT-сенсоры, подписавшись на топик `kvant/R22/BV/reception`.

## Использование

- После включения розетка подключается к Wi-Fi и MQTT-брокеру.
- На OLED-дисплее отображаются текущие значения: мощность (Вт), ток (А), напряжение (В), стоимость (руб) и cos φ.
- Данные автоматически отправляются на сервер раз в секунду.
- Через Telegram-бота (в разработке) можно запросить статистику.
- В Home Assistant данные появляются как сенсоры.

- по току: ≤ 0,09 А в диапазоне 0–5 А;
